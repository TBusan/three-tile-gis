# 基于 three-tile 改造的工程三维 GIS 引擎设计方案

> Version: v1.0  
> Author: ChatGPT  
> Design Goal：将 three-tile 改造成支持工程坐标系（Project CRS）的三维 GIS 引擎。

---

# 一、设计目标

## 1.1 目标

构建一个基于 Three.js 的工程级 GIS 引擎。

支持：

- CGCS2000 GK111
- CGCS2000 GK114
- EPSG:3857
- UTM
- 自定义 Project CRS

支持数据：

- XYZ
- WMTS
- GeoTIFF
- DEM
- GeoJSON
- DXF
- PointCloud
- GPR

核心目标：

> **数据保持原始工程坐标，不进行投影转换。**

GPU 精度问题采用：

- Local Origin
- RTC（Relative To Center）
- Floating Origin

解决。

# 三、设计原则

## 3.1 Project CRS First

整个工程只有一个 Project CRS。

例如：

```
Project

↓

CGCS2000 GK114
```

所有数据：

- GeoTIFF
- DEM
- DXF
- GeoJSON

全部保持：

```
CGCS2000 GK114
```

不进行：

```
CGCS2000

↓

WGS84

↓

ECEF
```

---

## 3.2 数据保持原始坐标

例如：

```
X = 512345.123

Y = 3654321.456

Z = 25
```

引擎内部：

仍然：

```
512345.123

3654321.456
```

不修改。

---

## 3.3 GPU使用Local Origin

进入GPU：

```
Tile Origin

512000
3654000
```

Geometry：

```
345.123

321.456
```

保证GPU精度。

# 六、TileScheme设计

不使用传统：

```
XYZ Tile
```

而采用：

```
Project Tile
```

例如：

```
TileSize

500m
```

根据工程坐标计算：

```
tileX=floor(worldX/tileSize)

tileY=floor(worldY/tileSize)
```

例如：

```
world

512345

3654321
```

得到：

```
tile

1024

7308
```
